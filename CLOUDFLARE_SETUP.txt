Cloudflare Pages 추천 API 현재 운영 설정

1. 현재 연결 상태
   - Pages 프로젝트: globalhot
   - Wrangler profile: globalhot-kintube
   - D1 database: globalhot-recommendations
   - Database UUID: 866c176d-9335-4545-b21f-2eff64c044cb
   - Binding name: DB
   - RECOMMENDATION_SALT: 기존 Cloudflare Secret을 사용한다. 실제 값은 저장소나 문서에 기록하지 않는다.
   - 적용 완료 migration: 0001_recommendations.sql, 0002_real_profiles.sql

2. 필수 릴리스 순서
   1) D1 백업을 먼저 만든다. 2026-08-01 전환 전 백업은 C:\tmp\globalhot-recommendations-pre-real-20260801.sql이다.
   2) npx wrangler d1 migrations list globalhot-recommendations --remote 로 적용 상태를 확인한다.
   3) npx wrangler d1 migrations apply globalhot-recommendations --remote 로 migration을 적용한다.
   4) 원격 DB에서 실존 프로필 6명, is_demo=0, 추천 수를 확인한다.
   5) npm run build:pages 와 npm test를 실행한다.
   6) Preview를 배포하고 화면·모바일·추천 API QA를 수행한다.
   7) Production을 배포한다.
   8) canonical https://globalhot.net 및 /api/recommendations를 다시 QA한다.

   D1 migration은 Pages보다 반드시 먼저 적용한다. 현재 CI에는 원격 migration 자동 적용 단계가 없으므로 이 순서는 수동으로 지켜야 한다.

3. 현재 추천 API 계약
   - GET: /api/recommendations
   - POST 예시: /api/recommendations/enako
   - 추천 식별은 IP와 secret salt의 SHA-256 가명 해시를 사용하며 User-Agent는 입력에서 제외한다.
   - 모델별 1회, 해시별 시간당 20회로 제한한다.
   - 레거시 is_demo=1 행은 보존하고 API에서는 is_demo=0 실제 프로필만 노출한다.

   - Preview URL: https://1b32892d.globalhot.pages.dev

5. 광고 정책 현재 상태
   - AdSense는 사용하지 않는다.
   - popunder, clickunder, 강제 리디렉션, push 구독 유도 광고는 금지한다.
   - 실제 광고 네트워크는 아직 연결하지 않았다. 화면의 광고 영역은 placeholder이며, 새 네트워크 도입 전 정책·동의·사업자 정보를 갱신한다.
