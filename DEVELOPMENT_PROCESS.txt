GLOBALHOT DEVELOPMENT PROCESS

1. 문서 목적 및 상시 갱신 규칙

이 파일은 GlobalHot의 개발 방향, 결정 사항, 검증 결과, 다음 작업을 한곳에 기록한다.
모든 작업이 완료되면 담당자는 이 파일의 변경 이력에 해당 작업을 추가하거나 갱신한다.
구현 코드와 이 문서의 내용이 다를 때에는 현재 코드 상태를 사실로 기록하고, 목표 방향은 별도로 표시한다.
비밀값, API 키, 광고 계정 ID, 개인 정보는 이 파일에 절대 기록하지 않는다.

3. 역할 분담: Advisor와 Worker

- Advisor: 요구사항 분석, 범위·위험 판단, 설계 결정, Worker 작업 브리프 작성, diff 검토, 테스트 실행, 승인 및 사용자 보고를 맡는다.
- Worker: 코드와 테스트를 작성·수정한다.
- 검증이 실패하면 Advisor는 수정 브리프를 작성하여 Worker에게 반환한다.
- 1~2줄 수준의 사소한 마무리만 Advisor가 직접 처리할 수 있다.

4. 표준 작업 흐름

1) 요청 확인
2) Git 상태와 현재 코드 점검
3) 범위, 영향, 저작권·개인정보·광고 위험 판단
4) 완료 기준과 테스트를 포함한 Worker 브리프 작성
5) Worker 구현
6) Advisor가 변경 diff 검토
7) 테스트 및 필요 시 브라우저 QA 수행
8) 이 DEVELOPMENT_PROCESS.txt 갱신
9) 사용자에게 결과, 검증, 남은 위험과 다음 행동 보고
10) 커밋은 사용자가 명시적으로 요청하거나 승인한 경우에만 수행

5. 단계별 로드맵

Phase 0. 기존 기반 보존 및 이전 결정
- 기존 정적 뉴스 사이트를 유지할지, 별도 경로/새 구조로 이전할지 결정한다.
- 기존 배포와 사용자 소유 파일에 영향을 주지 않는 이전 경로를 선택한다.
- 현재 뉴스 자동 발행은 수동 전용으로 전환했고, 기존 posts는 보존하되 sitemap에서 제외했다.

Phase 1. 포털 MVP 및 콘텐츠 모델
- 모델, 태그, 게시물, 출시 정보, SNS 업데이트의 데이터 모델을 정의한다.
- 모델 목록, 모델 프로필, 최신 업데이트, 태그 탐색의 기본 화면을 만든다.

Phase 2. 추천 및 랭킹
- 익명 사용자의 중복 추천을 방지한다.
- 추천 API에 속도 제한을 둔다.
- 추천 수에 따른 정렬, 검색, 인기 랭킹을 제공한다.

Phase 3. 수집·AI·권리 추적
- 허용된 출처만 수집하는 흐름을 만든다.
- AI 요약은 출처와 검토 상태를 함께 기록한다.
- 각 이미지와 콘텐츠에 출처, 라이선스/사용 권한, 확인 일자를 기록한다.

Phase 4. SEO 및 다국어
- 모델·태그·출시 페이지의 고유 메타데이터, 구조화 데이터, 사이트맵을 추가한다.
- 한국어 기반으로 시작하고 필요한 언어를 순차적으로 지원한다.

Phase 5. 수익화 및 최적화
- 광고 품질, 이탈률, 제휴 전환을 측정해 수익 구조를 조정한다.
- 직접 광고는 충분한 트래픽과 신뢰가 쌓인 뒤 검토한다.

6. 현재 수익화 결정

- AdSense 승인에 의존하지 않는다.
- 제휴 링크를 우선 수익원으로 둔다.
- SAFE 페이지(일반 모델 프로필, 코스프레, 랭킹)에는 Adsterra 네이티브/배너를 사용한다.
- SUGGESTIVE 페이지(그라비아, 수영복 등)에는 ExoClick 네이티브/배너만 조건부로 사용한다.
- 18+ 콘텐츠는 현재 범위에서 제외한다.
- 팝언더, 클릭언더, 강제 리디렉션, 푸시 구독 유도 광고는 사용하지 않는다.
- 초기에는 페이지당 광고를 최대 2개로 제한한다.
- 이용자 동의 후에만 광고 스크립트를 로드한다.
- ads.txt에는 광고망 승인 후 해당 광고망이 제공한 항목만 등록한다.
