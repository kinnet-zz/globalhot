# globalhot.net — 실시간 화제 랭킹 허브 설계서 (v0.1)

> 컨셉 A: 그라비아/화제영상 계열 "지금 급상승" 순위 사이트 (사이트명/도메인: **globalhot.net** 그대로 사용)
> 기존 자산 계승: 도메인(globalhot.net), Cloudflare Pages+D1, 피드 수집 파이프라인, 모델명 데이터(롱테일 SEO용)

## 1. 사이트맵

```
/                      실시간 급상승 TOP 50 (임베드 카드 타임라인)
/ranking/hourly        시간별 순위 (1h/6h/24h 탭)
/ranking/weekly        주간 순위 아카이브
/ranking/monthly       월간 순위 아카이브
/r/[slug]              개별 항목 상세 (임베드 + "왜 화제?" AI 요약 + 순위 이력)
/t/[name]              인물별 페이지 ("○○ 최신 화제 콘텐츠" — 롱테일 SEO 허브)
/tag/[tag]             태그별 순위
/search                검색
/about /privacy /terms 법적 페이지 (기존 재사용)
```

페이지 자동 증식: 매시간 순위 확정 → 항목 상세/인물/아카이브 페이지 자동 생성 → sitemap 자동 갱신.

## 2. 화면 설계

### 홈 (실시간 랭킹)
- 상단: 시간 탭 (실시간 | 1시간 | 24시간 | 주간)
- **영상 백그라운드 히어로** (신규): 자체 보유 mp4를 muted/loop autoplay 배경으로 사용 — 첫 방문 체류시간·시선 끌기용. 모바일 데이터 절약(포스터+lazy), prefers-reduced-motion 대응. 추후 "이번 주 1위 콘텐츠 하이라이트" 클립으로 주기 교체
- 본문: 순위 카드 리스트 (순위변동 ↑↓NEW 배지, 썸네일, 제목=AI 요약 헤드라인, 인물 태그, 조회·언급 추이)
- 카드 클릭 → /r/[slug] 상세 (임베드 재생)
- 인피드 광고: 5위 뒤 1개, 이후 8개마다 1개
- 우측 사이드바(데스크톱): 고정 스티키 광고 300x600 + "지금 급상승 인물 TOP 10"

### 상세 (/r/[slug])
- 임베드 플레이어 (X/YouTube 공식 임베드만, 다운로드 없음)
- "왜 화제?" AI 요약 2~3문장 (오리지널 텍스트 = 색인 자산)
- 순위 이력 그래프 (몇 위 → 몇 위)
- "같은 화제 더보기" 관련 항목 → 체류 연장
- 광고: 상단 728x90, 본문 하단, 관련 목록 사이 인피드

### 인물 페이지 (/t/[name])
- 헤더: 인물명 + 한 줄 소개 (기존 models.json bios 계승)
- "최신 화제 콘텐츠" 최신순 + "역대 최고 화제" TOP 5
- 광고: 상단 + 인피드

## 3. 랭킹 집계 로직

### 데이터 소스 (전부 공개 피드·링크 수집, 콘텐츠 복제 없음)
| 소스 | 용도 | 방식 |
|---|---|---|
| Mastodon 공개 타임라인 | 언급량·미디어 | 계승 (기존 issue 파이프라인) |
| Flickr 공개 피드 | 이미지 화제 | 계승 |
| yande.re/Safebooru API | 이미지 화제 | 계승 |
| Google News RSS | 뉴스 언급량 | 계승 |
| YouTube 검색 API | 신작 영상 | 신규 (API 키 발급) |
| X (수동/반자동) | 화제 영상 | 신규 — URL 등록 임베드 |

### 점수 계산 (t = 항목, w = 시간윈도우)
```
hot_score(t, w) =
    mentions(t, w) * 10        // 소스별 언급/게시 수
  + engagement_delta(t, w) * 5 // 조회·즐겨찾기 증가율 (절대량 아닌 변화율)
  + freshness(t) * 8           // exp(-age_hours / 12)
  + source_diversity(t, w) * 6 // 여러 소스에서 동시 언급 시 가산 (조작 방지)
  - decay_repetition(t)        // 72h 이상 지속 항목 감쇠 (신규 화제 우대)
```
- 시간윈도우: 1h / 6h / 24h / 7d
- 집계 주기: GitHub Actions 매시간 → D1 upsert → 순위 스냅샷 저장(이력 그래프용)
- 스팸/중복: 동일 미디어 해시 그룹핑, 단일 소스 폭주 감소항

### D1 스키마 (요약)
- items(id, type, source, url, media_hash, person_id, created_at)
- mentions(item_id, source, count, window_key)
- rank_snapshots(window, item_id, rank, score, captured_at)
- persons(id, name_ko, name_en, slug, bio)
- summaries(item_id, text, model, created_at) — AI 요약 캐시

## 4. 광고 슬롯 배치

| 위치 | 형식 | 네트워크 |
|---|---|---|
| 홈 인피드 (5위 뒤, 이후 8개마다) | 네이티브 인피드 | Adsterra/ExoClick |
| 홈 사이드바 스티키 | 300x600 | 병행 |
| 상세 상단 | 728x90/320x100 | 병행 |
| 상세 관련목록 사이 | 인피드 | 병행 |
| 랭킹 → 상세 이동 시 (1일 3회 제한) | 인터스티셜 | 단가 높은 네트워크 |
| 광고 차단 시 | 중립 폴백 (기존 ads.js 방식 계승) | — |

운영 원칙: 초기(일 1,000 UV 미만) 광고 최소화 → 색인·체류 확보 후 슬롯 증설. ads.txt 첫 배포부터 작성.

## 5. 단계별 로드맵

| 단계 | 목표 | 산출물 |
|---|---|---|
| P0 (1주) | 랭킹 엔진 MVP | 수집기 전환, 점수 계산, D1 스키마, 홈 TOP 50 |
| P1 (2주) | 색인 자산화 | 상세/인물/아카이브 페이지, sitemap 자동화, AI 요약 |
| P2 | 수익화 on | 광고 슬롯, ads.txt, GA4 퍼널 측정 |
| P3 | 증식 | YouTube 소스, 태그 자동화, 다국어 검토 |

## 6. 리스크
- 피드 소스 단절 → 다중 소스 분산으로 완화
- 니치 광고 단가 낮음 → 페이지 물량·재방문으로 커버
- 콘텐츠 저작권 → 임베드만(재게시 없음), 원본 삭제 시 자동 소실 허용
