자료 출처와 정정 원칙

GlobalHot은 금융·경제 정보를 설명할 때 공식 기관과 원문 자료를 우선합니다. 아래 목록은 모든 글에 동일하게 붙이는 장식용 출처가 아니라, 주제별 수치와 제도를 확인할 때 사용하는 기준 경로입니다.

출처 우선순위

  1. 중앙은행, 통계기관, 규제기관, 세무기관의 공식 자료
  2. 상장기업 공시와 기업의 공식 투자자 관계 자료
  3. 복수의 신뢰할 수 있는 경제·금융 매체 보도
  4. 시장 전망이나 의견은 사실과 구분해 가능성으로 표현

글별 출처 표기 기준

  1. 분석마다 서로 독립적인 원문 또는 공식 자료를 최소 3개 확인합니다.
  2. 수치, 날짜, 발언, 제도 설명은 해당 문단 바로 아래에 근거 링크를 표시합니다.
  3. RSS 제목과 요약만으로 확인할 수 없는 내용은 원문 대조 전 공개하지 않습니다.
  4. AI가 제안한 내용이라도 원문에서 확인되지 않으면 삭제합니다.
  5. 사실과 거리의악사의 해석을 구분하고, 불확실한 내용은 가능성으로 표현합니다.

정정과 업데이트

책임 편집자 거리의악사가 오류 제보를 확인합니다. 해당 수치와 문장을 원자료에서 다시 대조하고, 의미가 달라지는 오류는 본문과 최종 업데이트 날짜를 함께 수정합니다. 제도와 세율은 바뀔 수 있으므로 실제 신고나 투자 판단 전에는 반드시 해당 기관의 최신 안내를 확인해야 합니다.
