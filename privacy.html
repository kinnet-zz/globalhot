최종 업데이트: 2026-08-01

이 문서는 현재 GlobalHot에서 작동하는 기능과 그에 따른 정보 처리 방식을 설명합니다.

계정과 추천 저장

GlobalHot은 현재 회원가입, 계정, 댓글 기능을 제공하지 않으며 추천 사용자 계정을 저장하지 않습니다. D1이 연결되지 않았거나 초기 전역 추천 조회가 실패하면 추천은 기기 로컬 데모로 동작합니다. 전역 추천 조회가 성공한 뒤 개별 추천 전송이 실패하면 로컬 추천으로 바꾸지 않고 재시도를 안내합니다.

  • gh-consent-v1: 분석 동의 또는 거부 선택을 저장합니다.
  • globalhot-demo-recommendations-v1: D1 미연결 또는 초기 추천 API 조회 실패 시 이 기기에서 누른 데모 추천 ID 목록을 저장합니다.
  • globalhot-recommendations-v2: 서버 추천이 성공했거나 중복 추천으로 확인된 뒤, 이 브라우저에서 완료 버튼을 복원하기 위한 모델 ID 목록을 저장합니다.

전역 추천 처리

전역 추천이 활성화되면 Cloudflare 요청에서 IP 주소와 user-agent를 처리하고, 서버 비밀값을 함께 사용한 SHA-256 가명 해시 식별값을 만듭니다. 이는 완전 익명 처리라고 보장하는 표현이 아니며, 중복 추천 방지와 1시간 속도 제한을 위한 최소한의 식별 수단입니다.

D1 애플리케이션 데이터베이스에는 모델 ID, 가명 해시, 추천 시각만 저장합니다. 원본 IP 주소와 원본 user-agent는 애플리케이션 데이터베이스에 저장하지 않습니다. Cloudflare의 기술 로그 처리는 Cloudflare의 별도 정책과 운영 설정에 따릅니다.

호스팅과 기술 로그

사이트는 Cloudflare 기반으로 제공됩니다. 서비스 제공과 보안 운영 과정에서 IP 주소, user agent, 요청 URL, 요청 시간 등 기술 정보가 Cloudflare의 전송 또는 보안 로그에서 처리될 수 있습니다.

분석

Google Analytics 4는 gh-consent-v1 값이 accepted일 때만 로드됩니다. 현재 구성은 IP 익명화 옵션을 사용합니다. 동의를 거부해도 사이트를 이용할 수 있습니다. 각 제공사의 정보 처리 방식은 Cloudflare 개인정보처리방침과 Google 개인정보처리방침에서 확인할 수 있습니다.

광고와 제휴

현재 실제 광고 네트워크 스크립트는 사용하지 않으며, 페이지의 광고 자리는 안내용 placeholder입니다. 향후 광고 또는 제휴 기능을 도입하기 전 관련 정책, 동의 방식과 사업자 정보를 갱신하겠습니다.

기기 저장소 삭제와 문의

브라우저 설정에서 globalhot.net의 사이트 데이터 또는 localStorage를 삭제하면 위의 기기 저장값을 지울 수 있습니다. 기술 로그의 보관 기간과 처리 방식은 각 인프라 제공자의 정책에 따를 수 있습니다. 아동의 개인정보나 이 문서에 관한 문의는 admin@globalhot.net으로 보내주세요.
