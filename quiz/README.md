# GlobalHot 오늘의 폭락 60초

GlobalHot 안에서 운영하는 3문제·60초 경제 상황 퀴즈입니다. 매일 오전 6시 30분(KST/JST)에 검증된 문제은행을 바탕으로 자동 발행됩니다.

## 파일 구조

- `index.html`: 퀴즈 화면과 검색용 메타데이터
- `quiz.css`: GlobalHot 편집 디자인을 확장한 전용 스타일
- `quiz.js`: 최신·날짜별 로딩, 60초 타이머, 채점, 익명 연속 기록, 정답률과 결과 공유
- `data/YYYY-MM-DD.json`: 날짜별 퀴즈와 공식 출처
- `data/latest.json`: 기본 화면이 불러올 최신 날짜
- `bank/concepts.json`: 사람이 검증한 사실·정답·오답·해설·공식 출처
- `AUTOMATION_SPEC.md`: 생성·검증·실패 처리 명세
- `D1_SETUP.md`: 정답률 데이터베이스 활성화 절차

## 매일 자동 발행

1. 기존 일일 브리핑이 RSS와 Gemini로 오늘 뉴스를 정리합니다.
2. `generate-daily-quiz.mjs`가 최근 7일 문제를 피하고 의미·해석·확인 문제를 하나씩 고릅니다.
3. AI 문구는 정답·선택지·숫자·매매 권유 규칙을 통과할 때만 사용합니다.
4. AI가 실패하면 검증된 기본 문항으로 발행합니다.
5. 날짜 JSON과 `latest.json`, 홈페이지 티저를 갱신해 함께 커밋합니다.

문제은행에 새 카드를 넣을 때만 사람이 공식 출처, 정답, 오답, 숫자 기준일과 투자 조언 오인 가능성을 검수합니다. AI는 문항 표현 초안에만 사용됩니다.

테스트:
