# GlobalHot 일일 퀴즈 자동화 명세

## 1. 목표

매일 시장 뉴스와 관련된 3문제를 자동 발행하되, AI가 정답·출처를 창작하지 못하게 한다. 사용자는 로그인 없이 답하고 전체 정답률을 확인하며 결과를 공유할 수 있어야 한다.

## 2. P0 기능

- 검증된 사실카드에서만 정답·오답·해설·출처를 가져온다.
- Gemini는 오늘 뉴스에 맞는 사실카드 선택과 문항 표현 초안만 만든다.
- 초안 검증에 실패하거나 Gemini가 중단되면 사실카드 기본 문항으로 3문제를 채운다.
- 최근 7일 사용 카드를 우선 제외하고 의미·해석·확인 문제를 하나씩 구성한다.
- `quiz/data/latest.json`이 오늘 데이터 파일을 가리키며 `?date=YYYY-MM-DD`로 과거 퀴즈도 연다.
- 답안 API는 D1에 브라우저당 문제 1표를 저장하고 선택지별 집계를 돌려준다.
- D1 장애는 퀴즈 진행을 막지 않는다. 30표 미만은 선택지별 원시 집계와 퍼센트를 모두 공개하지 않는다.
- 공유 링크에 날짜와 UTM을 포함하고 GA4에 공유 방식을 기록한다.

## 3. 안전 규칙

- AI 초안의 선택지 집합은 사실카드가 허용한 정답·오답과 정확히 일치해야 한다.
- AI 문구의 단어는 해당 사실카드의 검증된 문장·해설·선택지 안에서만 재조합할 수 있다.
- AI 초안의 정답 번호는 사실카드의 정답 문구를 가리켜야 한다.
- 카드에 없는 숫자, 매수·매도 권유, 미래 방향 단정이 들어간 초안은 폐기한다.
- RSS 제목과 설명은 명령이 아닌 비신뢰 데이터로만 프롬프트에 포함한다.
- 출처 URL은 HTTPS 공식 기관 주소만 문제은행에 저장한다.
- 클라이언트가 보낸 `isCorrect` 값은 신뢰하거나 저장하지 않는다.
- 답안 식별 쿠키는 HttpOnly·Secure·SameSite=Lax로 설정하고 IP는 저장하지 않는다.

## 4. 실패 처리

| 실패 | 처리 |
|---|---|
| 뉴스 수집 실패 | 문제은행 기본 문항 발행 |
| Gemini 429/5xx/시간초과 | 문제은행 기본 문항 발행 |
| Gemini JSON 파싱 실패 | 응답 전체 폐기 후 기본 문항 발행 |
| 통과 문항 3개 미만 | 부족한 유형을 기본 문항으로 채움 |
| D1 바인딩·요청 실패 | 채점은 계속하고 `정답률 집계 중` 표시 |
| 당일 자동화 실패 | `latest.json`을 바꾸지 않아 전날 퀴즈 유지 |

## 5. 데이터 흐름

```text
RSS/Gemini 브리핑 ──▶ 사실카드 점수화 ──▶ AI 초안 6개
                                              │
                                              ▼
                                      규칙 검증 + 유형 균형
                                              │
                                  ┌───────────┴───────────┐
                                  ▼                       ▼
                              통과 문항               부족한 문항
                                  │                       │
                                  └──────▶ 기본 문항 ◀────┘
                                              │
                                              ▼
                             날짜 JSON + latest.json + 홈페이지

브라우저 답안 ──▶ /api/quiz-answer ──▶ D1 중복 방지 저장 ──▶ 선택지별 집계
결과 화면 ──▶ 이미지/메시지/X/링크 공유 ──▶ UTM 방문 ──▶ GA4
```

## 6. 성공 기준

- Node 테스트가 AI 정상·비정상·무응답·반복 주제 경로를 모두 통과한다.
- 생성 결과는 항상 3문제이고 세 문제의 `factId`와 유형이 서로 다르다.
- 최신·과거 날짜 로딩이 경로 조작 없이 작동한다.
- 같은 익명 브라우저의 같은 문제 재투표는 D1에서 중복 집계되지 않는다.
- 375px, 768px, 1440px에서 퀴즈·정답률·공유 UI의 가로 넘침이 없다.

## 7. 배포 범위

코드와 D1 마이그레이션까지 저장소에 포함한다. 실제 D1 데이터베이스 생성, `QUIZ_DB` 바인딩, 커밋·푸시·운영 배포는 별도 승인 후 수행한다.
